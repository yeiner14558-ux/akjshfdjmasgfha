# akjshfdjmasgfha

Proyecto académico cuyo objetivo es operar en el mercado de acciones y opciones financieras, con la meta de comprar una pizza al final del semestre... y que, más adelante, el conocimiento adquirido logre pagar mis necesidades.

## ¿Qué es esto?

Una app hecha con [Streamlit](https://streamlit.io/) para explorar y practicar conceptos de trading de acciones y opciones, gestionada con [uv](https://docs.astral.sh/uv/) como manejador de proyecto y dependencias.

## Requisitos

- [uv](https://docs.astral.sh/uv/) instalado.

## Cómo correr la app

```bash
uv run streamlit run app.py
```

Luego abre [http://localhost:8501](http://localhost:8501) en tu navegador.
